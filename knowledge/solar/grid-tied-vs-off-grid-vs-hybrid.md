# Grid-Tied vs Hybrid vs Off-Grid

## Grid-tied

No batteries. The system generates power during the day, the property uses what it needs, and any surplus is exported to the utility grid for a bill credit under net metering (see `net-metering-philippines.md`). At night, or whenever demand exceeds generation, the property simply draws from the grid as normal. This is the lowest-cost configuration and the common default when the grid supply is reliable. Its one real limitation: during a grid outage, a standard grid-tied system shuts down too — it isn't a backup power source.

## Hybrid

A grid-tied system plus battery storage. The battery captures surplus daytime generation instead of (or in addition to) exporting it, and can power the property — or at least essential circuits — during an outage. Popular in areas with unstable grid supply, or for customers who want backup resilience and better coverage of night-time usage, since it isn't purely dependent on real-time solar generation or grid draw. See `batteries.md` for when this configuration tends to make sense.

## Off-grid

No utility connection at all — full independence. This is the highest-cost configuration, because the panel array has to be oversized (there's no grid to cover a shortfall on a cloudy day) and the battery bank has to be sized to carry the property through at least a full day with zero sun. It suits remote sites without practical grid access. There's no monthly bill to offset in this configuration, so "savings" and "payback period" don't meaningfully apply the way they do for grid-tied or hybrid systems.

## Appliance-only systems — a special case

Some customers ask for solar sized to run just one appliance or a single room, rather than the whole property. EnergyWize can build that, and it's a legitimate request — but the general guidance is to recommend a whole-property system instead, for a few concrete reasons:

- Most of the hardware (panels, inverter, wiring) is needed regardless of scale, so the cost per usable watt is much higher for a small, isolated system.
- An appliance-only system can only offset that one load. A whole-property grid-tied system offsets everything on the meter and exports the surplus for net metering credit, so nothing generated goes to waste.
- When the target appliance is off, an isolated system has nowhere to send its output. A whole-property system still earns credit on that surplus.
- If the customer wants to expand later, an appliance-only setup usually has to be reworked rather than simply added to.

The honest exception: if the appliance is genuinely far from the main electrical service (a remote water pump, a detached shed, a farm site) where running power back to the main house is impractical, a dedicated system can be the right call on its own merits.
