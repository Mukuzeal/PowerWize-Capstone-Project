Three commitments, enforced in code

Each one is a property the system holds whether or not anyone is watching.

01

Payments and certificates are anchored to a public blockchain

Each settled payment and each issued certificate is hashed and written to Polygon. A QR code resolves to a public page that recomputes the hash and compares it against the chain, so a tampered record is detectable by an employer with no access to the system. The write is deliberately best-effort: a failed anchor never invalidates a paid enrolment or an earned certificate.

02

The solar consultant cannot invent numbers

Every figure quoted comes from a deterministic sizing engine, never from the language model. A post-generation check discards the model's text entirely if it contains a number matching no computed value. Off-topic questions are refused before a chat model is called at all.

03

Identity is verified before an account can exist

There is no public signup route. An account is created only by redeeming a token issued after an administrator reviewed a government ID and a selfie face-matched against it. Once review is complete the images are purged and only a digest remains as audit evidence.
